EisenScript reference
rule name { ... }Defines a rule. Rules with the same name compete at random.
rule name w 2Weight: how likely this version is to be picked.
rule name md 8 > endStops after 8 levels, then runs the rule end.
{ x 1 ry 30 } nameApplies a transform, then calls a rule or shape.
5 * { z 1 } nameRepeats, adding the transform each time.
x y zMove along an axis.
rx ry rzRotate in degrees around the box center.
s 2 or s 1 2 3Scale around the box center.
fx fy fz, mMirror, or apply a 3×3 matrix.
hue sat b aAdd to hue. Multiply saturation, brightness and alpha.
color #0afSet a color. color random picks from the color pool.
blend red 0.3Mix toward a color.
box sphere cylinder grid line dotShapes. Add a class with box::shiny. Cylinders run along x.
triangle[a;b;c]A triangle from three x,y,z points.
#define k 3Replaces the word k with 3.
set maxdepth 100Also: maxobjects, minsize, maxsize, seed, background, colorpool, recursion, syncrandom.
set colorpool list:a,bAlso: randomhue, randomrgb, greyscale, and image:name.jpg, which samples the picture you choose with Color image.
set raytracer::samples 16Also: shadows, phong, dof, ambient-occlusion-samples, shiny::reflection.
